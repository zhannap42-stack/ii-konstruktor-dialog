# ИИ-конструктор-диалог

Кликабельный диалоговый вариант прототипа «ИИ-конструктор» на React и @reactor/reactor.

Основа: https://github.com/zhannap42-stack/ii-konstruktor
Макеты: https://www.figma.com/design/oQw2hK8nCnK0ArdpYorVw3?node-id=366-35649

## Сценарий

Начать создание → данные TravelLine → дополнительные ссылки и файлы (необязательно) → брендбук, цвет или автоподбор → редактор → список созданных сайтов.

Возврат к ответу удаляет последующие сообщения, сохраняя заполненные поля, загруженные материалы и цвет. Новое создание из списка сайтов начинает отдельный сценарий. Каждый завершённый сценарий добавляет одну строку в таблицу.

Чат занимает доступную высоту окна, минимум 500 px. История прокручивается внутри. При сборе данных показывается анимированный Loader-bubble из UI Kit.

## Запуск

Нужен доступ к корпоративному npm registry для @reactor/reactor. Настройте локальный .npmrc самостоятельно — он не включён в репозиторий.

```sh
npm install
npm run dev
npm run build
npm run preview
```

Команда build создаёт автономный index.html для GitHub Pages, со встроенными ресурсами. development.html — точка входа для разработки.

## Границы прототипа

Данные TravelLine и генерация сайта имитируются. Файлы обрабатываются локально в браузере, серверной загрузки нет. Список созданных сайтов и черновики сохраняются только до перезагрузки страницы. Редактор показан изображением с рабочим возвратом к списку сайтов.
